# Insure360 AI

Customer Intelligence & Next Best Action Copilot built using Snowflake Cortex AI and Streamlit.

## Features
- Customer 360 View
- AI Generated Customer Summary
- Sentiment Analysis
- Next Best Action Recommendations
- Customer Timeline
- Portfolio Dashboard

## Technology Stack
- Snowflake
- Snowflake Cortex AI
- Streamlit
- SQL

## Data Sources
Structured:
- Customers
- Policies
- Claims
- Payments

Unstructured:
- Customer Call Transcripts
